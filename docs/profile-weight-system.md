## 设计原则说明

1. **中文理解 (D8) 全局保底**：所有 Profile 至少 10%，因为用户是中文环境，中文能力是基础门槛
2. **工具调用/Agent (D7) 按 Agent 化程度分配**：Researcher(25%) > Coder(20%) > Planner(15%) > Doubter(8%) > Reviewer(5%) > Writer(2%)
3. **编程 (D2) 集中在执行层**：Coder(30%) 和 Reviewer(25%) 占大头，其他 Profile 除非直接涉及代码否则权重低
4. **数学+科学推理 (D3+D4) 集中在质疑层**：Doubter 合计 40%，反映"质疑方案"核心依赖逻辑和科学素养
5. **长文本 (D5) 集中在信息密集型**：Writer(15%) 和 Researcher(15%) 需要处理长文档
6. **综合能力 (D1) 普遍较高**：Planner 最高(25%)，因为规划需要全局视野
7. **指令遵循 (D6) 执行导向型较高**：Planner(20%)、Coder(15%)、Writer(15%)、Reviewer(15%) 需要严格遵循规范
